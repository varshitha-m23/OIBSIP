# Task 1 – Retail Sales EDA

## Objective

The objective of this project is to perform Exploratory Data Analysis on retail sales data to identify sales trends, understand customer demographics, analyse product categories, and generate actionable business insights.

## Dataset

Retail Sales Data Set

## Key Analysis

- Dataset structure and data quality inspection
- Descriptive statistics
- Monthly sales trends
- Quarterly sales trends
- Customer age-group analysis
- Gender distribution
- Revenue by product category
- Top-selling product analysis
- Correlation heatmap
- Average transaction value by age group

## Outcome

The analysis provides insights into customer behaviour, sales performance, product categories, and potential areas for improving marketing and inventory decisions.

# Task 2 – Customer Segmentation Analysis

## Objective

The objective of this project is to segment customers based on their purchasing behaviour using RFM analysis and K-Means clustering.

## Dataset

Online Retail Dataset

## Key Analysis

- Dataset inspection and cleaning
- Missing-value handling
- Transaction filtering
- Recency calculation
- Frequency calculation
- Monetary value calculation
- RFM analysis
- Feature standardisation
- Elbow Method
- K-Means clustering
- Customer cluster profiling
- Cluster visualisations
- Marketing recommendations

## Outcome

Customers are divided into meaningful behavioural segments that can help businesses create targeted marketing strategies, loyalty programs, and customer retention campaigns.

# Task 3 – Wine Quality Prediction

## Objective

The objective of this project is to build and compare machine-learning classification models for predicting wine quality based on physicochemical properties.

## Dataset

Red Wine Quality Dataset

## Machine Learning Models

- Random Forest Classifier
- Stochastic Gradient Descent (SGD) Classifier
- Support Vector Classifier (SVC)

## Key Analysis

- Dataset inspection
- Descriptive statistics
- Wine quality distribution
- Feature distribution analysis
- Correlation heatmap
- Quality-class transformation
- Stratified train-test split
- Feature standardisation
- Model training
- Accuracy evaluation
- Precision, Recall and F1-score
- Confusion matrices
- Model comparison
- Random Forest feature importance

## Outcome

The performance of multiple classification algorithms is compared to identify the most suitable model for predicting wine quality categories.
